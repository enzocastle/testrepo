Introduction



In this project, we will investigate which audio features of a song can be used to predict a song's popularity. Below is a table of all the features included in the data set.
| Feature | Description | Range / Unit |
|---|---|---|
| Popularity | Spotify popularity score | 0–100 |
| Danceability | Suitability for dancing | 0–1 |
| Energy | Intensity and activity of the track | 0–1 |
| Loudness | Average loudness | Decibels (dB) |
| Speechiness | Presence of spoken words | 0–1 |
| Acousticness | Likelihood that the track is acoustic | 0–1 |
| Instrumentalness | Likelihood that the track has no vocals | 0–1 |
| Liveness | Likelihood of a live recording | 0–1 |
| Valence | Musical positivity or happiness | 0–1 |
| Tempo | Speed of the track | Beats per minute (BPM) |
| Duration | Length of the track | Milliseconds |
| Key | Estimated musical key | 0–11 |
| Mode | Major or minor mode | 0 or 1 |
| Time Signature | Estimated beats per measure | Integer |
| Explicitness | Contains explicit lyrics | True/False

For our research question, the features we will use for our analysis include: danceability, energy, loudness, speechiness, acousticness, instrumentalness, liveness, valence, and tempo. Popularity is based off of total number of plays a track has and how recent those plays are. The initial data set has 114000 entries.

Cleaning


Before we begin our analysis, we first take out songs with duplicate entries and songs with missing values. There is only one song with missing columns. It has a track ID, but no name, artist, or popularity. Therefore we will remove the song from our data. There are 24,259 songs with duplicate track ID's in our dataset. We will also drop these songs to prevent repeated entries from disproportionately affecting our analysis.

Aside from missing data and duplicate ID's, we noticed that there was a high amount songs with a popularity score of 0,1, and 2. There are two explanations for this. The first is that these songs were recently uploaded to spotify at the time of data collection and have not had the time to gather plays. The second is because some songs show up multiple times, yet have different track ID's. This is because they are apart of "collection albums," which are essentially a playlist of songs that are under the same category. The songs in these albums tend to have a much lower score than the song uploaded by the original artist, so we remove them from the data to get a better estimation of our features.
